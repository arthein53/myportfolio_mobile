# MyPortfolio Mobile

Aplikasi Flutter dasar untuk portofolio pribadi Arlen, dibuat untuk Tutorial 08 PBP.

## Fitur Tutorial 08

- `MyHomePage` berbasis `StatelessWidget`
- Komponen reusable `InfoCard` dan `ItemCard`
- Identitas pemilik: nama, NPM, dan kelas
- Menu Lihat Proyek, Tambah Proyek, dan Logout
- Warna kartu menu berbeda dan umpan balik `SnackBar`
- Dukungan Android, iOS, web, Linux, macOS, dan Windows dari satu codebase

## Menjalankan

```bash
flutter pub get
flutter run -d chrome
```

## Verifikasi

```bash
flutter analyze
flutter test
flutter build web
```
